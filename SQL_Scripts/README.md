# SQL Sales Analysis

This folder contains the SQL scripts used for the E-Commerce Sales Data Pipeline project.

The SQL analysis focuses on preparing the sales database, validating successful transactions, and generating business insights from the sales data.

---

## 📌 SQL Script

The main SQL analysis file is:

**`ECommerce_Sales_Analysis.sql`**

---

## 🎯 Objectives

The SQL analysis was designed to:

- Create the E-Commerce sales database and table
- Retrieve valid sales transactions
- Analyze revenue by city
- Identify products with the highest quantity sold
- Prepare structured data for further Power BI analysis

---

## 🗄️ Database Structure

### Database
`ECommerce_DB`

### Main Table
`sales_data`

### Key Columns

| Column | Description |
|---|---|
| `transaction_id` | Unique transaction identifier |
| `customer_id` | Customer identifier |
| `product_name` | Name of the product |
| `quantity` | Quantity sold |
| `price_per_unit` | Price per unit |
| `total_revenue` | Revenue generated by the transaction |
| `city` | Customer/sales city |
| `status` | Transaction status |

---

## 🔎 SQL Analysis

### 1. Valid Sales Transactions

Filters the dataset to include only transactions where:

`status = 'OK'`

This ensures that the analysis is based on valid sales records.

### 2. Revenue by City

Calculates total revenue generated by each city and ranks cities from highest to lowest revenue.

**Business Question:**

> Which cities generate the highest sales revenue?

### 3. Products by Quantity Sold

Calculates the total quantity sold for each product and ranks products from highest to lowest.

**Business Question:**

> Which products have the highest sales volume?
